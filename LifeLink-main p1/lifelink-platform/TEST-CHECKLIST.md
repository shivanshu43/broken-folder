# Test Checklist

## Before A Change Is Complete

- Validate request and authorization paths.
- Verify legal workflow transitions.
- Verify transactional inventory quantities.
- Verify notification audience and delivery fallback.
- Verify audit records for state-changing actions.
- Verify RAG sources and live-data separation.
- Verify prediction limitations are visible.
- Run typecheck, lint, unit, integration, and end-to-end checks when implemented.
