# LifeLink Platform

## Project Structure

- `apps/web`: role-based Next.js interface
- `apps/api`: API, workflows, authorization, notifications, and audit
- `packages/database`: Prisma and operational repositories
- `packages/shared`: cross-layer contracts and workflow vocabulary
- `packages/rag`: approved-source retrieval and grounding boundaries
- `services/analytics`: forecasting and shortage-risk service
- `docs`: requirements and analysis-model placeholders
- `infra`: local services and deployment boundaries

## Implementation Status

Function signatures and responsibility hints are scaffolded. Business logic, dependencies, schema fields, and test cases remain implementation work.
